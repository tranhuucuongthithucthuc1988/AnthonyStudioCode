Trình soạn thảo mã nguồn HTML gọn nhẹ, mạnh mẽ và mượt mà dành cho Windows. Viết HTML nhanh hơn với autocomplete thông minh, live server tích hợp, minimap và hơn 20 phím tắt chuyên nghiệp — tất cả trong 1 file .exe duy nhất.

Tính Năng Nổi Bật

Được thiết kế tối giản nhưng cực kỳ mạnh mẽ.

🎨 Giao diện chuyên nghiệp

  • Dark theme chuyên nghiệp, tone cam (#ff8a3d) và xanh (#3fa9ff)
  • Sidebar duyệt thư mục với icon trực quan
  • Tab bar đa file, dấu ● báo file chưa lưu
  • Minimap bên phải, gutter số dòng tự động
  • Current line highlight — dòng đang edit được tô sáng

📝 Soạn thảo thông minh

  • Syntax highlighting cho HTML/CSS/JS/Python/Markdown/YAML
  • Autocomplete tag HTML theo ngữ cảnh
  • Auto-close tag — gõ <div> tự đóng </div>
  • Auto-pair ngoặc (), [], {}, "", ''
  • Emmet — gõ ! + Tab → tạo boilerplate HTML5
  • Multi-cursor — Alt+Shift + kéo chuột chọn cột

🌐 Live Server tích hợp

  • Bật/tắt bằng 1 nút, không cần extension
  • Tự động reload khi file thay đổi
  • Hỗ trợ HTML/CSS/JS/Image trong thư mục
  • Tự dò cổng 5500–5529 nếu bị chiếm
  • Không inject script trùng — không phá code

💾 Lưu trữ an toàn

  • Atomic save — ghi file tạm rồi rename, chống corrupt
  • Auto-save tùy chọn (3 giây sau khi ngừng gõ)
  • Session restore — mở lại tab + zoom + cài đặt
  • Hỗ trợ UTF-8 với BOM (tiếng Việt, emoji)
